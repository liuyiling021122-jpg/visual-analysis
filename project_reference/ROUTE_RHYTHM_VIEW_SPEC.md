## 1. 整体结构定义

### 1.1 RouteRhythmView 是什么

RouteRhythmView 是一个**二维矩阵式路径节律图**。它把一条养蜂迁徙路线展开为"时间轴（X）× 空间轴（Y）"的网格结构，每个交叉点表达一个路线节点在该时间、该地点的花期-天气-停留综合信息。

**不是**地图（虽然 Y 轴有空间维度）。
**不是**传统甘特图（虽然 X 轴有时间维度）。
**是**两者的融合——Y 轴按纬度排列的省份节点 + X 轴时间流动 + 节点间的斜向迁移连线 = 蜂农"追花"动作的视觉轨迹。

### 1.2 结构元素清单

| 元素 | 说明 | 数据来源 |
|:---|:---|:---|
| **X 轴（时间）** | 跨年月份轴，从路线首段的 start_month 到末段的 end_month。东线示例：11月 → 次年 8月 | `data_migration_routes_detailed` start_month/end_month |
| **Y 轴（空间）** | 省份/地点列表，按 `to_lat` 纬度从低到高排列（南→北）。同省地点合并为一行 | `to_lat`, `to_location` |
| **节点（RouteNode）** | 每个路段在矩阵中占据一个矩形区域，X 位置由 start_month/start_day → end_month/end_day 决定，Y 位置由 to_location 决定 | 路段数据 |
| **路径连线** | 连接相邻 segment_order 节点的有向曲线/折线，箭头表示迁徙方向（南→北 或 北→南） | segment_order, from_location → to_location |
| **信息层按钮** | 横向排列的 toggle，控制花期条/天气热力/风险标注等的显示/隐藏 | — |
| **Tooltip** | 鼠标悬停节点时浮出的摘要卡片 | weather_daily 聚合指标 |
| **Weather Detail Panel** | 点击节点后在主视图下方/右侧展开的逐日天气详图 | weather_daily 逐日数据 |

### 1.3 坐标映射

```
X 轴映射：
  像素 X = f(日期)
  日期范围 = [路线最小 start_date, 路线最大 end_date]
  X 轴以"月"为刻度标签，每月等宽

Y 轴映射：
  像素 Y = f(to_lat)  // 纬度线性映射
  Y 轴标签 = to_location（省份名 + 可选城市名）
  Y 轴排序 = 纬度升序（南→北）

节点矩形：
  left   = f(start_date)
  right  = f(end_date)
  top    = f(to_lat) - nodeHeight/2
  bottom = f(to_lat) + nodeHeight/2
  width  ∝ stay_days（停留越久越宽）
  height = 固定行高

路径连线：
  从 (prev_end_date, prev_to_lat) → (curr_start_date, curr_to_lat)
  箭头端点在当前节点的左边缘
```

## 2. 单个 RouteNode 视觉编码

以下表格定义了**一个 RouteNode 在矩阵中的全部视觉通道**。

### 2.1 节点整体

| 信息 | 数据字段 | 视觉编码 | 示例值（山东·刺槐） |
|:---|:---|:---|:---|
| 节点 X 位置 | `start_month`, `start_day` → `end_month`, `end_day` | 横向矩形，左边缘 = 到达日，右边缘 = 离开日 | 5/2 → 5/22 |
| 节点 Y 位置 | `to_lat` | 在 Y 轴上放置于对应纬度行 | 36.65°N |
| 节点宽度 | `stay_days` | 矩形宽度 ∝ 停留天数（1天 ≈ X像素） | 20天 |
| 节点高度 | — | 固定行高 | 48px |
| 节点颜色基调 | — | 浅灰底 + 叠加信息层 | #F5F5F5 |

### 2.2 默认表层（始终可见）

| 信息 | 数据字段 | 视觉编码 | 示例值 |
|:---|:---|:---|:---|
| **地点名** | `to_location` | 白色圆角标签，置于节点左上角，字体 11px | "山东" |
| **蜜源名** | `nectar_sources` | 紧跟地点名之后，灰色文字，字体 10px，前加 🌼 icon | "🌼 刺槐" |
| **停留天数** | `stay_days` | 节点右上角，小圆 + 数字 | "⏱ 20天" |
| **迁徙方向指示** | `from_location` → `to_location` | 进入节点的连线末端箭头；离开节点的连线起点在节点右边缘 | ← 从江苏进入 / 从山东离开 → |
| **路线序号** | `segment_order` | 节点左上角小圆圈数字 | "④" |

### 2.3 花期蜜源层（信息层开关控制）

| 信息 | 数据字段 | 视觉编码 | 示例值 |
|:---|:---|:---|:---|
| **理论花期条** | flowering `start_month`, `end_month` | 半透明横条，覆盖整个花期月份。颜色按 `honey_grade`：一等=金色 #FFD700，二等=银色 #C0C0C0，三等=铜色 #CD7F32 | 4月-5月，金色条 |
| **盛花月标记** | flowering `peak_month` | 在花期条上的 peak_month 位置叠加 ◆ 菱形标记 | 4月位置有 ◆ |
| **蜜质等级** | flowering `honey_grade` | 花期条右侧小标签 | "一等蜜" |
| **预期产量** | flowering `nectar_yield_kg_per_colony` | 花期条右侧小字 | "20~40 kg/箱" |
| **适宜泌蜜温度** | flowering `temp_range_c` | 花期条左侧小字 | "27°C" |

**注意**：理论花期条在 X 轴上的位置可能与蜂农停留窗口**错位**——这是核心视觉对比：
- 花期条 = "植物什么时候开花"
- 停留窗口 = "蜂农什么时候在这"
- 重叠区 = "有效采蜜机会"

### 2.4 天气窗口层（信息层开关控制）

| 信息 | 数据字段 | 视觉编码 | 示例值 |
|:---|:---|:---|:---|
| **逐日 NWI 热力条** | weather_daily `nectar_weather_index`（停留期内 `in_stay_period=1` 的所有行） | 细竖条矩阵，每根竖条 = 1天。颜色：绿(NWI≥80)→黄(60-79)→橙(40-59)→红(<40) | 20 根竖条，大部分绿色，3 根橙色 |
| **good_honey_day 标记** | weather_daily `good_honey_day = 1` | NWI 热力条顶部叠加绿色小三角 ▲ | 17个 ▲ |
| **降水标记** | weather_daily `precipitation_mm` | NWI 热力条底部蓝色竖线，高度 ∝ 降水量 | 3天有蓝色线，最高 12mm |
| **平均 NWI** | weather_daily 聚合 `avgNWI` | 节点右下角，小徽章 | "NWI 83" |
| **有效采蜜率** | weather_daily 聚合 `goodHoneyRate` | 节点右下角，小徽章 | "采蜜率 85%" |

### 2.5 风险标注层（信息层开关控制，默认关闭）

| 信息 | 数据字段 | 视觉编码 | 示例值 |
|:---|:---|:---|:---|
| **连续恶劣天气带** | weather_daily `bad_weather_streak ≥ 3` | 在 NWI 热力条上方叠加半透明红色背景带，宽度 = 连续天数 | 5/15-5/17 三天红色横带 |
| **最长连续恶劣天数** | weather_daily 聚合 `maxBadStreak` | 节点底部中央，红色小标签 | "⚠ 最长连续 3 天" |
| **高温日标记** | weather_daily `temp_max_c > 35` | 红色温度计 icon，标注在对应日期位置 | 🌡 |
| **暴雨日标记** | weather_daily `precipitation_mm > 25` | 深蓝色雨滴 icon，标注在对应日期位置 | 💧 |
| **有效窗口缩短警示** | 当 `goodHoneyRate < 0.5` 时 | 节点整体边框变为红色虚线 | — |

### 2.6 授粉标注层（数据有限，默认关闭，预览标记）

| 信息 | 数据字段 | 视觉编码 | 说明 |
|:---|:---|:---|:---|
| **授粉案例标记** | `pollination_service_market` `region` 匹配当前 `to_location` | 节点右侧一个小蜂巢 icon 🏠，hover 显示案例摘要 | **数据不足**：仅 23 个案例，且无经纬度，无法精确匹配路段。仅当 province 匹配时标注。 |
| **附近果园作物** | `fruit_data_merged` `main_provinces` 匹配 | 节点底部灰色小字，如"附近：苹果园" | **数据不足**：无具体坐标。可作为解释文本 |

### 2.7 收益/风险提示（节点右上角标签）

| 信息 | 数据字段 | 视觉编码 | 示例值 |
|:---|:---|:---|:---|
| **气候风险摘要** | weather_daily 聚合 `climateRiskIndex` | 彩色圆点：绿(<0.3)/黄(0.3-0.6)/红(>0.6) | 🟡 0.42 |
| **模式利润参考** | `beekeeper_profit_by_mode` `intensive_migratory_profit_per_colony`（按年份匹配） | 节点右上角小字 | "参考利润 ¥329/箱" |

## 3. 三种交互状态

### 3.1 默认状态（Default）

**触发**：用户从地图选择路线后，中央视图首次渲染。

**显示内容**：

| 始终可见 | 默认打开的信息层 | 默认关闭的信息层 |
|:---|:---|:---|
| 节点矩形 + 地点名 + 蜜源名 + 停留天数 | ☑ 路线连线 + 方向箭头 | ☐ 风险标注层 |
| 路径连线 + 迁移方向箭头 | ☑ 花期蜜源层（理论花期条 + 盛花标记 + 蜜质等级） | ☐ 授粉标注层 |
| Y 轴省份标签 + X 轴月份刻度 | ☑ 天气窗口层（NWI 热力条 + good_honey_day ▲） | ☐ 收益风险层 |

**视觉呈现**：
- 所有节点大小一致（统一 48px 高）
- NWI 热力条缩略显示（仅颜色块，无数字）
- 无 tooltip
- Weather Detail Panel 收起

### 3.2 Hover 状态（Hover）

**触发**：鼠标悬停在某个节点矩形区域上。

**变化**：

| 元素 | 变化 |
|:---|:---|
| **当前节点** | 轻微放大（scale 1.05）+ 外发光（drop-shadow）+ 边框加粗（2px → 3px） |
| **其他节点** | 透明度降低到 40% |
| **Tooltip 卡片** | 在节点附近浮出（优先右侧，空间不足时左侧） |
| **路径连线** | 当前节点上下游的连线高亮（颜色加深） |
| **Weather Detail Panel** | 不展开 |

**Tooltip 卡片内容**：

```
┌─────────────────────────────────┐
│ ④ 山东 · 刺槐                     │  ← 序号 + 地点 + 蜜源
│ ─────────────────────────────── │
│ 📅 停留：5月2日 - 5月22日（20天）   │  ← stay_start → stay_end
│ 🌸 理论花期：4月 - 5月（盛花 4月）   │  ← flowering start/end + peak
│ 🌸 蜜质：一等蜜 | 产量：20~40 kg/箱  │  ← honey_grade + nectar_yield
│ ─────────────────────────────── │
│ ✅ 有效采蜜日：17/20（85%）         │  ← goodHoneyRate
│ 📊 平均 NWI：83                   │  ← avgNWI
│ ⚠ 最长连续恶劣：3天                │  ← maxBadStreak
│ 🌡 平均温度：19.5°C               │  ← AVG(temp_mean_c) WHERE in_stay=1
│ 🌧 降水日：3天（最大 12mm）         │  ← COUNT(precip>0) + MAX(precip)
│ ─────────────────────────────── │
│ 🟡 气候风险：0.42（中等）           │  ← climateRiskIndex
│ 💰 参考利润：¥329/箱（大转地 2023） │  ← profit_per_colony
│ ─────────────────────────────── │
│ 点击查看逐日天气详情 →              │
└─────────────────────────────────┘
```

**数据不足标注**：如果该省的天气数据缺失（如山东 2005 年），tooltip 中天气相关行替换为"⚠ 该年份天气数据暂缺，以下为邻近年份估算"。

### 3.3 Click 状态（Click）

**触发**：用户点击某个节点。

**变化**：

| 元素 | 变化 |
|:---|:---|
| **当前节点** | 边框变为选中色（蓝色 3px solid）+ 节点下方展开 Weather Detail Panel |
| **其他节点** | 保持透明度 100%（不淡化，方便对照） |
| **Weather Detail Panel** | 从节点下方/右侧滑出展开（见第 4 节） |
| **路径连线** | 当前节点的上下游连线加粗 |
| **地图选择器** | 当前节点对应的省份锚点脉冲动画 |
| **收益面板** | 更新到当前路线/模式/年份的数据 |

**再次点击已选中的节点**：收起 Weather Detail Panel，恢复默认状态。

## 4. Weather Detail Panel 设计

### 4.1 位置与布局

Weather Detail Panel 在主视图**下方**展开（不是右侧——中央主视图宽度优先）。它是一个水平滚动的逐日卡片序列。

```
┌──────────────────────────────────────────────────────────────────┐
│ 中央主视图（节点被选中，高亮）                                        │
├──────────────────────────────────────────────────────────────────┤
│ ▲ 山东 · 刺槐 | 5月2日-5月22日 | 共20天                              │
│ ┌────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬───→ 可滚动  │
│ │5/2 │5/3 │5/4 │5/5 │5/6 │ ...                                  │
│ │NWI │NWI │NWI │NWI │NWI │                                       │
│ │ 85 │ 88 │ 92 │ 90 │ 87 │                                       │
│ │ ▲  │ ▲  │ ▲  │ ▲  │ ▲  │                                       │
│ │ ☀  │ ☀  │ ☀  │ ☁  │ ☀  │                                       │
│ └────┴────┴────┴────┴────┴───                                    │
│ 汇总：适宜 17/20 | 降水日 3 | 高温日 0 | 最长连续恶劣 3天            │
│ 解释：5月15-17日连续3天中雨中断采蜜，该段损失约15%理论采蜜机会         │
└──────────────────────────────────────────────────────────────────┘
```

### 4.2 单日卡片设计

每个卡片 = 1 天。一屏显示约 14-20 张卡片，超出的水平滚动。

```
     ┌─────────┐
     │  5/2    │  ← 日期（月/日）
     │  周四    │  ← 星期（可选）
     ├─────────┤
     │  NWI    │
     │  ████░░ │  ← NWI 热力条（横向柱状，总长 100%）
     │   85    │  ← NWI 数值
     ├─────────┤
     │ ▲       │  ← good_honey_day = 1 时显示绿色 ▲
     │         │     good_honey_day = 0 时显示灰色 ─
     ├─────────┤
     │ 🌡 22°C │  ← temp_max_c（日最高温）
     │   8°C   │  ← temp_min_c（日最低温）
     ├─────────┤
     │ 🌧 0 mm │  ← precipitation_mm（降水量）
     │ 💨 11   │  ← wind_max_kmh（最大风速）
     ├─────────┤
     │ ☀ 12h  │  ← sunshine_hours（日照时数）
     ├─────────┤
     │  streak │
     │    0    │  ← bad_weather_streak
     └─────────┘

颜色规则：
  NWI 热力条:  绿 ≥80 / 黄 60-79 / 橙 40-59 / 红 <40
  good_honey_day ▲: 绿色
  good_honey_day = 0: 灰色横线
  降水 > 0: 蓝色数值
  降水 > 5mm: 蓝色数值 + 雨滴 icon
  降水 > 25mm: 深蓝背景
  temp_max > 35°C: 红色数值
  bad_weather_streak ≥ 3 的日期: 卡片左侧红色边框
```

### 4.3 汇总栏

Panel 底部固定一个汇总栏，始终可见（不随每日卡片滚动）：

```
┌─────────────────────────────────────────────────────────────┐
│ 📊 汇总统计                                                  │
│ ├ 总停留天数：20天                                           │
│ ├ 适宜采蜜日：17天（good_honey_day=1）                       │
│ ├ 有效采蜜率：85%（17/20）                                   │
│ ├ 平均 NWI：83（范围 60-92）                                 │
│ ├ 平均温度：19.5°C（最高 26.2°C / 最低 9.8°C）               │
│ ├ 降水日数：3天（总降水 18.4mm，最大单日 12mm）               │
│ ├ 高温日数（>35°C）：0天                                    │
│ ├ 最长连续不适宜采蜜：3天（5/15-5/17）                       │
│ ├ 日照不足日（<3h）：1天                                     │
│ └ 气候风险等级：🟡 中等（0.42）                              │
│                                                             │
│ 💡 解读：花期全覆盖，但 5/15-5/17 连续 3 天中雨打断采蜜。     │
│    刺槐花期仅 7-10 天，盛花期在 4 月——                      │
│    蜂农 5 月初到达时可能已错过盛花期。                        │
│    建议对比 1980s/2000s 年代同段数据，观察花期是否在提前。     │
└─────────────────────────────────────────────────────────────┘
```

**解读文本的数据来源**：
- "花期仅 7-10 天" → `flowering_calendar` 中刺槐的 `notes` 字段："洋槐蜜花期仅7-10天水白透明"
- "盛花期在 4 月" → `peak_month = 4`
- "蜂农 5 月初到达" → `start_month = 5, start_day = 2`
- 此处**数据本身揭示了一个潜在问题**：蜂农到达时间可能偏晚

## 5. 信息层按钮设计

### 5.1 按钮列表

所有按钮放置在主视图**顶部水平工具栏**：

```
[☑ 路线层] [☑ 花期层] [☑ 天气层] [☐ 风险层] [☐ 缓冲期] [☐ 授粉层⚠] [☐ 收益标签]
 默认      默认      默认      高级      高级      预览数据   高级
```

### 5.2 各层详情

#### ☑ 路线层（Route Layer）— 始终打开，不可关闭

| 属性 | 说明 |
|:---|:---|
| **数据来源** | `data_migration_routes_detailed` |
| **视觉增加** | 节点矩形、地点标签、蜜源名、停留天数、路径连线、方向箭头、segment_order 序号 |
| **为什么不可关闭** | 这是主视图的骨架，关闭后只剩空白坐标轴 |

#### ☑ 花期蜜源层（Flowering Layer）— 默认打开

| 属性 | 说明 |
|:---|:---|
| **数据来源** | `flowering_calendar_by_province` |
| **视觉增加** | 理论花期半透明横条（金色一等/银色二等/铜色三等）、盛花月 ◆ 标记、蜜质等级标签、预期产量数字 |
| **关键分析价值** | 花期条与停留窗口的**位置对比**是系统核心洞察——重叠区 vs 错位区 |
| **注意** | 花期条跨越整个理论花期月份（如刺槐 4-5 月），可能比节点矩形宽 |

#### ☑ 天气窗口层（Weather Layer）— 默认打开

| 属性 | 说明 |
|:---|:---|
| **数据来源** | `weather_daily_migration_routes`（`in_stay_period=1`） |
| **视觉增加** | 逐日 NWI 热力竖条（绿/黄/橙/红）、good_honey_day ▲ 标记、降水蓝色竖线 |
| **关键分析价值** | 将"理论可采"转化为"实际可采"——展示天气如何压缩有效窗口 |

#### ☐ 风险标注层（Risk Layer）— 默认关闭，高级分析

| 属性 | 说明 |
|:---|:---|
| **数据来源** | weather_daily 的 `bad_weather_streak`, `temp_max_c`, `precipitation_mm` |
| **视觉增加** | 连续恶劣天气红色半透明背景带、最长连续恶劣天数标签、高温/暴雨 icon 标记 |
| **为什么默认关闭** | 风险标注视觉冲击力强，初次查看时容易分散注意力。应在用户初步理解路线结构后再打开 |

#### ☐ 缓冲期层（Buffer Layer）— 默认关闭，高级分析

| 属性 | 说明 |
|:---|:---|
| **数据来源** | weather_daily `buffer_before=1` 和 `buffer_after=1` 的数据 |
| **视觉增加** | 节点左右各延伸 10 天的半透明条纹区域（纹理填充），标注"到达前/离开后" |
| **分析价值** | 回答"蜂农到达前后天气是否已经/仍然适合采蜜"——判断到达时机是否合理 |
| **为什么默认关闭** | 缓冲期分析是进阶问题，主线理解不需要 |

#### ☐ 授粉层（Pollination Layer）⚠ — 默认关闭，预览数据

| 属性 | 说明 |
|:---|:---|
| **数据来源** | `pollination_service_market`（23 个案例） + `fruit_data_merged` |
| **视觉增加** | 节点旁小蜂巢 icon 🏠（仅当 province 匹配时）；hover 显示该省已知授粉服务案例和价格范围 |
| **⚠ 数据不足说明** | `pollination_service_market` 仅 23 个离散案例，无经纬度、无年份序列，无法精确匹配路段。仅作为**参考标注**。 |
| **建议** | 按钮旁标注 ⚠，hover 时显示"数据有限，仅展示附近已知案例" |

#### ☐ 收益标签层（Profit Label Layer）— 默认关闭，高级分析

| 属性 | 说明 |
|:---|:---|
| **数据来源** | `beekeeper_profit_by_mode`（按年份+模式匹配） |
| **视觉增加** | 节点右上角显示"参考利润 ¥329/箱"标签小字；气候风险圆点 |
| **注意** | 这是**路线对应模式**的全国均值，不是该路段的具体收益。标签旁应有小问号 icon，hover 说明"全国大转地均值，非本路段实测" |
| **为什么默认关闭** | 收益讨论应由右侧收益面板主导，主视图上的标签是辅助定位 |
