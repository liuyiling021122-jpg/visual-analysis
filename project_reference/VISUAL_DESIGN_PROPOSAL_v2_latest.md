| 设计点 | 缺失说明 | 处理方式 |
|:---|:---|:---|

## B. 设计思路评估

### B.1 新三段式 vs 旧三段式的对比

| 维度 | 旧方案（DESIGN_DOC.md） | 新方案（本提案） |
|:---|:---|:---|
| 主视图定位 | 地图流向图是主视图 | 地图降级为**路线选择器**，中央"路径节律图"升为主视图 |
| 叙事逻辑 | "先看空间分布，再看时间细节" | "先选路线 → 专注理解该路线的时空节律 → 再解释经济后果" |
| 多路径对比 | 地图上多线叠加（视觉拥挤） | 中央主视图切换为多列并排对比模式 |
| 收益面板 | 收益-风险散点矩阵 | 保留但改造为"生计风险解读面板"——包含成本拆解、市场波动、气候风险条形图 |
| 核心问题 | "哪些路线存在，气候如何影响采蜜" | "**为什么蜂农选择这条路线？花期、天气、收益如何共同决定路线的可行性？**" |

### B.2 新三段式优点

1. **路径优先**：地图不再是"数据展示板"，而是"交互入口"——用户先选想研究的路线，再深入。这符合"转地路线是蜂农的核心决策对象"。

2. **中央主视图聚焦单一分析任务**：不像传统仪表盘同时展示多张图让用户自行拼凑，而是用一张集成图回答"这条路线在什么时间、什么地点、采什么花、天气好不好、有什么风险"。

3. **信息层分层**：通过开关按钮控制花期层、天气层、风险层等的叠加，避免一屏信息过载。

4. **收益面板有叙事性**：不是纯粹的散点图，而是提供"解释"——这条路线为什么利润高/低？成本花在哪？气候风险多大？

### B.3 潜在问题与应对

| 问题 | 应对 |
|:---|:---|
| 中央"路径节律图"是全新视觉形式，用户需要学习成本 | 默认显示引导 tooltip + 底部图例永久可见 |
| 多路径比较时，中央视图可能拥挤 | 最多同时比较 3 条路线（超过则提示"请先取消选择"） |
| 收益面板与中央视图的信息映射不如矩阵直接 | 在收益面板中始终高亮当前路线对应的模式点，保持视觉锚定 |
| 授粉层、农药层数据不足，可能导致信息层按钮为空 | 默认隐藏这些层，标记为"预览/有限数据"；点击时如实说明数据覆盖范围 |

### B.4 是否比旧方案更适合本项目

**是**。理由：

- 本项目的独特性不在于"多图表"，而在于"追花迁徙路径"这一纵向叙事。旧方案的"地图+甘特图+矩阵"是通用分析模式，但新方案的"路径选择器→路径节律图→生计解释"更贴合蜂农的实际决策逻辑。
- 新方案为**答辩叙事**提供了天然的故事线："选一条路 → 看懂这条路 → 理解这条路背后的经济账"。

### B.5 需要收束的信息点

以下内容**不放入主视图**，仅作为 tooltip / 侧栏展开：

- 全国农药使用趋势 → 收益面板底部的微型趋势线
- 各省蜂群数量 → 地图锚点 tooltip
- 授粉服务具体价格案例 → 收益面板中的列表/表格
- 蜂农个案描述文本 → 中央视图的节点 tooltip 引用

## C. 新设计方案总览

### C.1 系统核心问题（一句话）

> **花期不等于有效采蜜期，有蜜源不等于有收益——中国流动养蜂人的路线选择，是花期预期、天气窗口、运输成本与市场价格四方博弈的结果。**

### C.2 三个视图的任务分工

```
┌────────────────────────────────────────────────────────────┐
│                  【视图1】边角路线地图                        │
│                  任务：路线发现 & 选择入口                     │
│                  "有哪些路线？它们在空间上怎么走？"              │
│                                                             │
│  用户操作：单选/多选路线 → 触发中央视图刷新                     │
├────────────────────────────────────────────────────────────┤
│                                                            │
│              【视图2】中央路径节律主视图                       │
│              任务：时空节律深度分析                            │
│              "这条路线的花期-天气-停留如何配合？"               │
│                                                            │
│  信息层：☑花期蜜源 ☑天气窗口 ☑路线节点 ☐授粉 ☐风险           │
│  模式切换：单路径分析 / 多路径比较                             │
│                                                            │
├────────────────────────────────────────────────────────────┤
│                 【视图3】生计风险解读面板                       │
│                 任务：经济解释 & 因果支撑                      │
│                 "为什么这条路线的收益是这么多？"                 │
│                                                             │
│  模块：收益趋势 / 成本结构 / 气候风险 / 市场价格 / 模式对比      │
└────────────────────────────────────────────────────────────┘
```

### C.3 各视图使用的数据字段

#### 视图 1（边角路线地图）

| 视觉元素 | 数据字段 | 来源 |
|:---|:---|:---|
| 路线弧线 | from_lat/lng → to_lat/lng, route_name | `data_migration_routes_detailed` |
| 弧线颜色 | route_type（classic=蓝, variant=绿, beekeeper_case=橙） | 同上 |
| 节点位置 | to_lat/lng（每段终点） | 同上 |
| 节点标注 | to_location, nectar_sources | 同上 |
| 路线标签 | route_name, route_description | 同上 |
| 选中高亮 | selectedRoute（Store） | Store |
| 多选序号 | 用户选择顺序 (1/2/3) | Store |

#### 视图 2（中央路径节律主视图）

| 信息层 | 视觉元素 | 数据字段 | 来源 |
|:---|:---|:---|:---|
| **路线节点层** | 节点位置、顺序连线 | segment_order, to_location, start/end_date, stay_days, nectar_sources | `data_migration_routes_detailed` |
| **花期蜜源层** | 横条 | start_month, end_month, peak_month, honey_grade, nectar_yield | `flowering_calendar_by_province` |

### C.4 三视图联动逻辑

```
用户在地图点击"东线（沿海线）"
        │
        ├──→ 中央视图：加载东线全部 8 段，按月份展开路径节律图
        │        默认打开：路线节点层 + 花期蜜源层 + 天气热力层
        │        默认关闭：授粉标注层、风险标注层（可手动打开）
        │
        └──→ 收益面板：高亮"大转地"模式（东线=大转地）
                显示大转地历年利润趋势 + 成本结构
                X 轴年份光标同步到地图的年代滑块

用户点击中央视图某个节点（如"山东·5月·刺槐"）
        │
        ├──→ 地图：该节点对应的省份锚点脉冲动画
        │
        ├──→ 中央视图：该节点展开显示详细天气热力
        │        tooltip 显示：有效采蜜率 17/20 = 85%，最长连续恶劣 3 天
        │
        └──→ 收益面板：显示该路线/模式的 cost_income_ratio
                 标注"运输成本占总成本 27%"

用户在地图上追加选择"西线（西北线）"
        │
        ├──→ 中央视图：切换为"多路径比较模式"
        │        左列=东线，右列=西线
        │        Y 轴（省份）对齐，便于逐省对比
        │
        └──→ 收益面板：两条路线对应的模式点都高亮
                 柱状对比：东线单箱利润 vs 西线单箱利润

用户在收益面板点击"2023 年"数据点
        │
        ├──→ 地图：路线的年代切换到 2020s 版本
        │
        └──→ 中央视图：天气数据切换到 2024 年
```

## D. 中央"路径节律主视图"重点细化

这是全系统最关键的设计决策。以下逐项说明。

### D.1 视觉形式：**横向时间轴 + 纵向省份轴线 = 路径节律矩阵**

**不是普通地图，也不是传统甘特图。**

```
                 ←──── 时间轴（月份，跨年 11月 → 次年 9月）────→
                 11月  12月   1月   2月   3月   4月   5月   6月   7月   8月   9月
    ┌──────────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
    │ 福建      │     │▓▓▓▓▓│     │     │     │     │     │     │     │     │     │
    │ (26.1°N) │     │越冬  │     │     │     │     │     │     │     │     │     │
    ├──────────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┼─────┤
    │ 广东      │▓▓▓▓▓│░░░░░│     │     │     │     │     │     │     │     │     │
    │ (23.1°N) │荔枝  │越冬  │     │     │     │     │     │     │     │     │     │
```

### D.2 为什么这种形式适合"追花迁徙"

1. **横向 = 时间**：蜂农决策的第一维度是"什么时候去哪"。横向时间轴天然表达"追逐花期"。
2. **纵向 = 空间**：省份按纬度排列（南→北），对应蜂农的南北迁徙方向。节点间的斜向连接线形成"追花路径"的视觉节奏。
3. **矩阵格子 = 路径 × 时间的交叉点**：每个格子展示"在这个时间、这个地点发生了什么"——花期条（理论）、停留窗口（实际）、天气热力（现实约束）。
4. **视觉节奏**：从左上（冬/华南）向右下（秋/西北）的阶梯状布局，直观呈现"追花"的时空节律。

## F. Case Study 候选

### F.1 Case 1：东线山东段 — "花期全覆盖但被连续暴雨打断"

**入口**：用户在地图点击"东线（沿海线）" → 中央视图自动展开 → 点击山东·5月·刺槐节点

**系统显示**：
- 理论花期：4月-5月（刺槐），盛花 4 月
- 蜂农停留：5月2日-5月22日，20天
- 花期覆盖：100%（停留完全在花期内）
- **但**：逐日天气热力显示，停留期内出现了一段 `bad_weather_streak = 3` 的连续中雨（降水量 8-12mm/day）
- 有效采蜜率：17/20 = 85%（3 天被雨打断）
- NWI 在降雨日骤降至 60 以下

**Panel 补充**：收益面板显示大转地模式 2023 年单箱利润约 329 元，但蜂农在该段损失了 3 天采蜜窗口，相当于损失约 15% 的理论采蜜机会。

**叙事价值**：**"花期全覆盖 ≠ 有效采蜜期全覆盖"**——这是系统要传达的核心洞察。理论花期 100% 匹配，但 3 天暴雨就可以显著影响实际产出。

---

### F.2 Case 2：西线青海段 — "花期提前 + 蜂农到达偏晚 = 窗口错位"

**入口**：用户在地图选择"西线（西北线）"→ 切换到 2020s 年代 → 查看青海·6月·油菜/山花节点

**系统显示**：
- 理论花期：青海油菜（春油菜）5-7 月
- 蜂农停留：5月28日-6月27日（2020s 版本）
- 对比 2000s 版本：花期提前了约 2 天（基于 `climate_factors` 中青海邻近省份的 `花期提前(天)` 字段推算）
- 缓冲期分析：`buffer_before` 的前 10 天中，5月20日前后的天气已经适宜采蜜——**说明蜂农到达时花期可能已经开始了一周以上**
- 有效采蜜窗口可能已经错过了盛花期 peak_month

**Panel 补充**：叠加 1985→2005→2024 三代的气候数据对比（打开"气候年代对比"层），显示气温上升趋势导致高山春油菜花期逐渐提前。

**叙事价值**：**"气候变化正在压缩蜂农的容错窗口"**——花期提前 + 路线固定 = 到达时机偏离盛花期，即使天气好也可能采不足蜜。这是对蜂农路线决策的长期挑战。

---

### F.3 Case 3：东线 vs 西线收益对比 — "同样是大转地，利润差在哪"

**入口**：用户同时选择东线和西线 → 中央视图进入双列比较 → 收益面板显示大转地全国均值

**系统显示**：
- 东线：10 省 / 3,500km / 有效采蜜率平均 ~78% / 蜜源等级一等为主
- 西线：8 省 / 3,500km / 有效采蜜率平均 ~72% / 蜜源有老瓜头（二等）、棉花（三等）
- 收益面板：大转地 2023 年单箱利润 329 元、利润率 ~59%
- 成本结构：运输占 27%、饲料占 50%
- **关键对比**：东线多采一等蜜（刺槐、椴树，单价高），西线后半段以三等蜜为主（棉花，单价低但产量大）——**总利润相近但利润结构不同**：东线靠蜜质，西线靠蜜量。

**叙事价值**：**"收益不只由蜜源决定"**——路线长度相似、天气风险相近（东线暴雨多、西线干旱多），但蜜质等级和市场价格最终塑造了不同的收益结构。这也解释了为什么 2020s 年代越来越多的蜂农从长途大转地转向短途小转地 + 授粉服务。

## H. 设计决策说明（可写入最终系统文档）

### H.1 为什么以路径为核心

中国流动养蜂是一个以**路线决策**为中心的生产活动。蜂农的每一步——选择哪条路线、在哪停留多久、何时出发——都直接决定了全年收益。传统的"多图表仪表盘"虽然展示了各个维度，但**割裂了决策逻辑**。本系统将"路线"提升为第一等分析对象：用户从路线出发理解空间分布（地图），再从路线深入理解时空节律（路径节律图），最后从路线反推经济后果（收益面板）。这个设计让系统的叙事逻辑与蜂农的真实决策逻辑一致。

### H.2 为什么中央主视图重点展示花期—天气窗口

蜜源植物的花期是蜂农决定路线的基础依据，但**花期只是必要条件，不是充分条件**。在停留期间的实际天气——降雨、温度、日照——直接决定了蜜蜂能否出巢采蜜、植物能否正常泌蜜。系统的核心洞察"花期不等于有效采蜜期"只能通过**同时展示理论花期和实际天气窗口**来传达。将这两层信息叠加在同一时间轴上，是系统最有分析深度的设计点。

### H.3 为什么设置收益风险面板

采蜂路线的选择不仅仅是生物气象学问题，更是**经济决策问题**。如果只展示花期和天气，系统讲的是"能不能采到蜜"；加上收益面板，系统才能回答"采到蜜是否划算"。运输成本（占总成本 ~27%）、蜂蜜市场价格、授粉服务收入占比（近年升至 ~8-10%）、越冬损失率，这些经济变量才是蜂农最终决定"跑不跑这条路"的关键。收益面板承担的是**因果解释**角色，而非单纯的数据陈列。
