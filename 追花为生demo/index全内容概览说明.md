# 《追花为生》demo index 页面全内容概览说明

生成对象：追花为生demo/index.html  
页面标题：花期节律主视图 | 追花为生  
系统全称：中国流动养蜂人的迁徙、授粉与生计风险可视分析系统  
说明范围：以当前 index.html 实际加载的页面为准，即 index.html + js/flowering-rhythm.js + 动态注入的 route-map-panel、livelihood-risk-panel、tooltip-layer 组件，以及它们读取的数据和计算逻辑。

重要边界说明：

1. 当前 index.html 只加载 js/flowering-rhythm.js。项目中虽然还存在 top-toolbar.html、status-bar.html、route-rhythm-view.html、weather-detail-panel.html 和 app.js 等备用/早期模块，但这些并未被当前 index.html 挂载，因此不作为当前页面实际内容统计。
2. 当前页面没有显示年代切换工具，appState 默认年代为 2020s。因此路线地图、路线风险解释、花期节律主视图默认均以 2020s 数据运行。
3. 页面核心指标来自两类来源：一类是 route_segment_summary.csv 中已经预聚合好的路段指标；另一类是 weather_daily_migration_routes.csv 中逐日天气指标，页面会按路段停留期筛选并再次聚合。
4. NWI（nectar_weather_index，泌蜜天气指数）是逐日天气数据集中的预处理字段。项目文档说明它综合温度、日照、降水、日夜温差等因素，取值 0–100；当前前端读取、展示和求平均，但不在前端重新计算其内部权重。
5. climateRiskIndex（气候生产风险指数/生产风险指数）有明确公式，来自 scripts/generate-route-segment-summary.mjs，并在页面中被复用；南线在前端还会根据逐日天气进行运行时补算。

## 1. 页面总体目标

index 页面要回答的核心问题是：流动养蜂人在一年中如何随花期迁徙，不同路线中花期、停留期、天气适宜窗口、有效采蜜窗口是否匹配；这些错位如何转化为沿途生产风险，并进一步影响蜂农生计、利润模式、收支结构与产业市场环境。

页面不是单纯地图或图表，而是一个“路径节律 + 路线风险 + 生计解释”的联合分析界面。它把一年时间、迁徙空间、蜜源花期、逐日天气、采蜜有效性、路线风险和蜂农经营背景放在同一个交互系统里。

## 2. 页面实际结构

当前 index.html 的主体由四个区域组成。

### 2.1 顶部系统标题区

显示内容：

| 内容 | 定义 | 功能 |
|---|---|---|
| 追花为生 | 项目主标题 | 建立主题识别，强调蜂农“追花逐蜜”的迁徙生计逻辑 |
| Migration Beekeeping Visual Analysis | 英文系统说明 | 指明系统类型为流动养蜂可视分析 |
| 中国流动养蜂人的迁徙、授粉与生计风险可视分析系统 | 系统副标题 | 概括页面关注对象：迁徙、授粉、生计风险 |

### 2.2 左侧控制与路线地图区

位于主视图左侧，包含信息层开关和路线地图选择器。

功能：

- 控制中央路径节律主视图的信息层显隐。
- 选择一条或多条迁徙路线。
- 当四条主路线全部选中时，中央主视图自动进入四线合并对比模式。
- 通过路线地图点击或复选框改变 selectedRoutes，并联动右侧风险解释面板。

### 2.3 中央路径节律主视图区

页面主视觉区域，是当前 index 的核心。

功能：

- 以一年为时间轴，把路线停留、花期、天气适宜日、有效采蜜日、NWI 指数叠合在同一条迁徙弧线上。
- 支持单路线模式和四路线合并模式。
- 支持缩放、适配视图、L4 花期强度透明度调节。
- 支持点击 NWI 气泡进入逐日天气细节，点击路线段联动右侧风险链。

### 2.4 右侧生计风险解读面板

动态加载 livelihood-risk-panel.html，并由 livelihood-risk-panel.js 渲染。

功能：

- 解释当前路线的沿途生产风险。
- 展示迁徙风险链、路段风险、主要风险来源、采蜜率与 NWI。
- 提供全国蜂农经营压力、生计韧性、不同养殖模式利润、收支结构、蜂业规模、市场环境与农药背景。

### 2.5 浮动提示层

包含 tooltip-layer 和 rhythm-tooltip。

功能：

- 鼠标悬停路线段、NWI 日气泡、日历格、风险节点、图表点位时显示解释。
- 将字段值翻译成用户能直接读懂的说明，例如日期、NWI、天气描述、温度、降雨、风速、风险来源等。

## 3. 页面加载与数据流程

index.html 通过 js/flowering-rhythm.js 启动。启动流程如下：

1. loadComponents 加载组件插槽：route-map-panel、livelihood-risk-panel、tooltip-layer。
2. 读取 URL 参数 route。如果 URL 带有 ?route=east-coastal / west-northwest / central-route / south-route，则用该路线作为初始路线；否则默认 east-coastal。
3. 初始化路线地图面板。
4. 初始化右侧生计风险面板。
5. 加载当前路线定义。
6. 加载 L4 花期 SVG 图层。
7. 加载逐日 NWI 天气数据。
8. 加载 route_segment_summary.csv 中的路段指标。
9. 加载各路线弧线 SVG 并建立日期到弧线位置的几何映射。
10. 渲染 L2、L3、L5、NWI 等注记层。
11. 初始化 NWI 气泡、路线弧线、图层开关、缩放、日历、路线状态联动等交互。

## 4. 全局状态与联动变量

页面核心状态来自 js/state.js。

| 状态 | 默认值 | 定义 | 影响范围 |
|---|---:|---|---|
| selectedRoutes | east-coastal | 当前选中的路线集合 | 路线地图、中央主视图、右侧路线风险标签 |
| selectedEra | 2020s | 当前年代 | 路线段与风险数据筛选 |
| selectedMonthWindow | all | 月份窗口，当前 index 无独立控件 | 备用状态，对当前 index 影响较弱 |
| activeRiskRoute | east-coastal | 右侧风险面板当前解释的路线 | 路线风险解释、风险链 |
| selectedNode | null | 当前选中的路段节点 id | 中央路线高亮、右侧风险链聚焦 |
| selectedNodeSummary | null | 当前路段摘要，包括路线名、段序号、地点 | 地图当前点、风险链聚焦卡片 |

selectedRoutes 最多保留 4 条路线。四条主路线 east-coastal、west-northwest、central-route、south-route 同时被选中时，中央视图切换为四路线合并模式。

## 5. 左侧信息层开关

index.html 中的信息层开关共六项，每项对应中央主视图的一类视觉信息。

| 图层 | 页面名称 | 数据/资产来源 | 可视化内容 | 功能定义 |
|---|---|---|---|---|
| L1 | 时间基线 | L0-base.svg 或对应路线 L0.svg | 全年时间与地点迁徙弧线的基底结构 | 提供全年时间轴与路径轨道，是所有叠加层的坐标基底 |
| L2 | 停留时段 | route_segment_summary.csv 或东线硬编码段 | 每段迁徙在目的地停留的起止时间 | 告诉用户蜂农在何时停留于哪个地点 |
| L3 | 天气窗口 | weather_daily_migration_routes.csv 中 good_honey_day | 逐日天气适宜窗口 | 标记哪些日期天气条件适合采蜜 |
| L4 | 花期强度 | L4-flowering.svg 或各路线 L4.svg | 蜜源植物花期阶段与强度 | 表示当地蜜源植物花期是否与停留期重合 |
| L5 | 有效采蜜 | 由 L2、L3、L4 交集计算 | 同时满足停留、天气适宜、花期有效的日期 | 代表真正可能形成采蜜收益的窗口 |
| NWI | NWI 指数 | weather_daily_migration_routes.csv 中 nectar_weather_index | 路段平均 NWI 气泡、逐日 NWI 气泡、日历热力格 | 衡量天气对泌蜜和采蜜的综合适宜度 |

L4 强度滑杆控制花期图层透明度，取值 20%–100%。缩放控件包括适配、缩小、百分比显示、放大。

## 6. 路线地图选择器

路线地图组件为 route-map-panel。

### 6.1 地图内容

地图使用 china_l7_boundary_2025.json 绘制中国边界和区域背景，并使用 data_migration_routes_detailed.csv 绘制路线。路线通过经纬度投影到固定画布：

- 小地图画布：330 × 330。
- 放大地图画布：900 × 620。
- 经纬度范围：经度 73–135，纬度 17–54。
- 箭头表示迁徙方向。
- 节点表示路线经过地点。
- 线段表示地点之间的迁徙连接。

### 6.2 主路线选项

| routeId | 中文名称 | 颜色 | 页面含义 |
|---|---|---|---|
| east-coastal | 东线（沿海线） | 橙色 | 沿海/东部经典迁徙路径 |
| west-northwest | 西线（西北线） | 蓝绿色 | 西南至西北方向的经典迁徙路径 |
| central-route | 中线（京广线） | 土黄色 | 京广方向经典迁徙路径 |
| south-route | 南线 | 绿色 | 南部/中部蜜源迁徙路径 |

### 6.3 动态路线

除四条经典路线外，组件会从 data_migration_routes_detailed.csv 中自动提取 route_type 不等于 classic 的路线：

- variant：区域/变体路线。
- beekeeper_case：蜂农个案路线。

这些路线显示在“扩展路线”列表中，可加入地图对比。但中央路径节律主视图只有四条主路线有完整 SVG 资产；动态路线主要用于地图层展示，不一定进入中央花期节律主视图。

### 6.4 地图交互任务

| 任务 | 操作 | 系统响应 |
|---|---|---|
| 选择路线 | 点击复选框或地图路线 | 更新 selectedRoutes，地图显隐与右侧风险路线同步 |
| 路线对比 | 勾选多条路线 | 小地图与右侧标签显示多路线；四条主路线全选时中央进入合并视图 |
| 查看路线说明 | 悬停路线或节点 | 显示路线名、路段数、里程、蜜源说明 |
| 放大地图 | 点击地图空白或按 Enter/Space | 打开放大地图层，路线流线有动画 |
| 退出放大 | 点击收起、遮罩或 Escape | 关闭放大地图 |

## 7. 中央路径节律主视图：单路线模式

单路线模式显示当前 activeRiskRoute 对应的路线。默认是东线（沿海线）。

### 7.1 可显示路线

| routeId | 视觉资产 | 路段数 | 特殊说明 |
|---|---|---:|---|
| east-coastal | assets/flowering-rhythm/L0-base.svg、L4-flowering.svg、east-line-0 至 east-line-7.svg | 8 | 东线是手工校准参考视图，路段日期和花期窗口在 JS 中硬编码 |
| west-northwest | assets/flowering-rhythm/routes/west/L0.svg、L4.svg、line-*.svg | 7 | 路段来自 route_segment_summary.csv，使用几何算法重排 SVG 日期点 |
| central-route | assets/flowering-rhythm/routes/central/L0.svg、L4.svg、line-*.svg | 7 | 七个数据段共享六条视觉弧线，河南两段共用同一条 lane |
| south-route | assets/flowering-rhythm/routes/south/L0.svg、L4.svg、line-*.svg | 6 | 南线路段的逐日天气匹配在前端有特殊窗口约束 |

### 7.2 L1 时间基线

定义：全年日期在弧线上的基础轨道。  
作用：为 L2 停留、L3 天气、L5 有效采蜜和 NWI 标注提供空间定位。  
计算方式：每条路线的 SVG 中有代表日期单元的 path。前端通过 getBBox 取每个 path 的中心点，并按几何顺序排列为 1–365 日。

东线使用内置 eastArcModel，以两段半圆模型把日期映射到弧线。其他路线从 SVG path 自动排序，并用最小生成路径/邻近排序修正 SVG 导出顺序。

### 7.3 L2 停留时段

定义：蜂农在某段路线目的地停留的起止日期。  
数据来源：东线来自 JS 中 eastSegments；西线、中线、南线来自 route_segment_summary.csv 中 start_month、start_day、end_month、end_day。  
视觉：沿 L1 弧线绘制一段路径，并在两端用圆点标注起止。  
任务：判断蜂农何时到达某地点、停留多久、路线节奏是否连续。

### 7.4 L3 天气窗口

定义：逐日天气适宜采蜜日。  
数据来源：weather_daily_migration_routes.csv 中 good_honey_day = 1。  
数据说明：good_honey_day 标记当日是否适合采蜜，数据说明中解释为无雨、风力较小、温度适中等条件。  
视觉：在对应日期位置绘制细小路径段；在日历中以 L3 标记显示。  
任务：识别停留期内哪些天“天气上可采蜜”。

### 7.5 L4 花期强度

定义：蜜源植物处在花期的阶段与强度。  
数据来源：SVG 花期图层与 route_segment_summary.csv 中 flower_start_month、flower_end_month、flower_match_plant、flowering_months 等字段。  
视觉：作为花期色带/强度图层叠加在基底之上。  
任务：判断蜂农到达时蜜源是否开花，以及花期强度是否足以支撑采蜜。

东线的 L4 花期窗口在 JS 中手工定义，例如：

| 段 | 路线 | 日期 | 花期窗口 | 蜜源说明 |
|---:|---|---|---|---|
| 1 | 福建 → 广东 | 12/02–12/12 | 12/02–12/12 | 鸭脚木、野桂花补给；荔枝未开，仅低权重越冬补给 |
| 2 | 浙江 → 安徽 | 02/17–03/07 | 02/17–03/07 | 油菜、紫云英 |
| 3 | 江苏 → 江苏 | 04/02–04/22 | 04/02–04/22 | 甘蓝型油菜、紫云英，区域参考 |
| 4 | 山东 → 山东 | 05/02–05/22 | 05/02–05/10 | 刺槐，花期短 |
| 5 | 辽宁 → 辽宁 | 05/25–06/07 | 05/25–06/07 | 刺槐二趟，物候资料存在冲突 |
| 6 | 吉林 → 黑龙江 | 06/12–07/12 | 06/12–07/12 | 椴树 |
| 7 | 内蒙古 → 内蒙古 | 07/17–08/17 | 08/01–08/17 | 向日葵、胡枝子，胡枝子资料不足 |
| 8 | 广东 → 福建 | 11/12–11/28 | 11/12–11/28 | 枇杷、鸭脚木越冬补给 |

### 7.6 L5 有效采蜜窗口

定义：同时满足 L2 停留期、L3 天气适宜、L4 花期窗口的日期。  
公式：L5 = L2 ∩ L3 ∩ L4。  
代码判定：row.goodHoneyDay 必须为 true，且 row.ordinal 落在 segment.flowerWindows 内。  
视觉：以更强调的线段或深绿边标记在弧线/日历/合并视图上。  
任务：从“蜂农在那里”和“天气合适”进一步收窄到“有花可采且天气合适”的真正生产窗口。

### 7.7 NWI 指数

全称：nectar_weather_index，泌蜜天气指数。  
取值范围：0–100。  
数据来源：weather_daily_migration_routes.csv。  
含义：综合温度、日照、降水、日夜温差等因素评估当日泌蜜和采蜜适宜度；数值越高越有利。

页面使用方式：

1. 逐日读取每条 weather row 的 nectar_weather_index。
2. 对每个路段停留期内 in_stay_period = 1 的 dailyRows 求平均，得到 avgNWI。
3. 单路线概览中，每个路段显示一个 NWI 平均气泡。
4. 点击 NWI 气泡后，显示该路段逐日 NWI 气泡和停留期日历。
5. 四线合并模式中，每个日期小格或 NWI 点按逐日 NWI 映射颜色。

NWI 颜色映射：

- 代码用 progress = clamp((NWI - 40) / 50, 0, 1)。
- 低值颜色为 rgb(187,104,78)，偏红橙。
- 高值颜色为 rgb(73,151,108)，偏绿色。
- 因此 NWI ≤ 40 接近低值颜色，NWI ≥ 90 接近高值颜色。

NWI 气泡大小：

- 路段平均气泡半径约为 10 + ((NWI - 45) / 45) × 12。
- 逐日气泡半径也随 NWI 增大而增大。

### 7.8 NWI 逐日细节模式

触发：点击某个路段的 NWI 平均气泡。  
显示内容：

| 内容 | 定义 |
|---|---|
| 逐日 NWI 气泡 | 停留期内每天的 NWI 值，颜色和半径编码适宜度 |
| L2 STAY CALENDAR | 当前路段停留期日历 |
| L3 天数 | good_honey_day = 1 的天数 |
| L5 天数 | 同时满足停留、天气和花期的有效采蜜天数 |
| 平均 NWI | 当前路段停留期 dailyRows 的 NWI 平均值 |
| 天气 Tooltip | 日期、NWI、天气描述、最低/最高温、降雨、风速、连续不适宜天数 |
| Back | 退出 NWI 细节，恢复总览 |

### 7.9 路段索引和路线段交互

中央主视图会在每段中点放置 segment marker。  
悬停显示：段序号、from→to、日期、蜜源、注释。  
点击路线弧线：设置 selectedNodeSummary，并自动打开右侧“路线迁徙与沿途风险”页签，使风险链聚焦到同一路段。

## 8. 中央路径节律主视图：四线合并模式

触发条件：东线、西线、中线、南线四条主路线同时被选中。

视觉内容：

| 元素 | 定义 | 功能 |
|---|---|---|
| 四条横向时间弧 | Central、West、East、South 自上而下排列 | 同屏比较四条路线全年节奏 |
| 1 小格 = 1 天 | SVG 中每个日期 cell 对应一年中的一天 | 精确比较不同路线在同一天的状态 |
| 小格填色 | 停留时段/路段归属/NWI 颜色混合 | 表示当前日期属于哪一路段，以及天气适宜度 |
| L3 描边 | good_honey_day = 1 | 标注天气适宜日 |
| L5 深绿边 | L2 ∩ L3 ∩ L4 | 标注有效采蜜日 |
| 半透明粗线 | 该段停留时间与地点段 | 强化路段起止范围 |
| 大线路高亮 | 鼠标悬停某路线 | 联动右侧风险面板 activeRiskRoute |

## 10. 右侧标签一：路线迁徙与沿途风险

### 10.1 当前路线风险解释

显示指标：

| 指标 | 计算/来源 | 定义 | 页面解释 |
|---|---|---|---|
| 路段 | 当前路线、当前年代在 route_segment_summary.csv 中的路段数量 | 该路线被拆分为多少个停留/迁徙段 | 用于判断路线复杂度 |
| 里程 | sum(segment_km) | 当前路线所有路段里程之和 | 表示迁徙距离压力 |
| 平均采蜜率 | sum(good_days) / sum(weather_day_count) | 当前路线所有有天气记录停留日中，适宜采蜜日所占比例 | 越高表示天气窗口越充足 |
| 沿途平均风险 | mean(climateRiskIndex) | 当前路线各路段生产风险指数的简单平均值 | 越高表示天气条件对生产窗口压力越大 |

路线风险阅读规则：

- 沿途平均风险 ≥ 0.62：沿途有效采蜜窗口受限，气候生产风险偏高，可能增加单箱产出与收入不确定性。
- 0.38 ≤ 沿途平均风险 < 0.62：沿途生产窗口存在波动，可能对单箱产出稳定性形成压力。
- 沿途平均风险 < 0.38：沿途气候生产风险整体较低，经营压力更可能来自运输成本与市场价格。

### 10.2 生产风险指数 climateRiskIndex 的定义和公式

页面中的“生产风险指数”“气候生产风险指数”“沿途风险值”指同一个核心字段 climateRiskIndex。  
它是一个 0–1 指数：0 表示低风险，1 表示高风险。

逐路段公式：

climateRiskIndex = clamp(1 - goodHoneyRate + maxBadStreak / 12 + rainDays / weatherDayCount / 5 + heatDays / weatherDayCount / 4, 0, 1)

其中：

| 变量 | 来源 | 定义 | 风险含义 |
|---|---|---|---|
| weatherDayCount | 停留期内逐日天气行数 | 当前路段停留期间可用于分析的天气天数 | 分母 |
| goodDays | good_honey_day = 1 的天数 | 天气适宜采蜜日数量 | 越多风险越低 |
| goodHoneyRate | goodDays / weatherDayCount | 平均采蜜率 | 越低风险越高 |
| maxBadStreak | bad_weather_streak 最大值 | 停留期内最长连续不适宜采蜜天数 | 连续中断越长风险越高 |
| rainDays | precipitation_mm > 0 的天数 | 停留期内有降水的天数 | 降水越多采蜜窗口越不稳定 |
| heatDays | temp_max_c > 35 的天数 | 停留期内高温天数 | 高温暴露越多风险越高 |
| clamp | 截断函数 | 小于 0 取 0，大于 1 取 1 | 保证指数落在 0–1 |

公式解释：

- 1 - goodHoneyRate 是主项，表示有效天气窗口不足。
- maxBadStreak / 12 表示连续不适宜天气造成的中断压力。12 天被用作归一化尺度。
- rainDays / weatherDayCount / 5 表示降水暴露，权重相对较低。
- heatDays / weatherDayCount / 4 表示高温暴露，权重略高于降水暴露。
- 四项相加后再 clamp 到 0–1，所以该指数不是加权平均，而是“生产压力叠加后截断”的风险指数。

风险等级：

| climateRiskIndex | 等级 | 页面含义 |
|---:|---|---|
| ≥ 0.80 | 高 | 生产窗口承压明显 |
| 0.50–0.79 | 中 | 生产窗口存在波动 |
| < 0.50 | 低 | 生产窗口相对稳定 |

风险链颜色：

| 数值范围 | 颜色语义 |
|---:|---|
| ≥ 0.90 | 深红，高风险 |
| 0.65–0.89 | 橙红，较高风险 |
| 0.35–0.64 | 琥珀，中等风险 |
| < 0.35 | 绿色，低风险 |

主要风险来源的判定：

页面将四个风险分量排序，最大者作为“主要风险来源”：

1. 有效采蜜窗口不足 = 1 - goodHoneyRate。
2. 持续中断压力 = maxBadStreak / 12。
3. 降水暴露 = rainDays / weatherDayCount / 5。
4. 高温暴露 = heatDays / weatherDayCount / 4。

## 17. 当前路线风险解释的完整读法

以默认东线（沿海线）2020s 为例：

1. 路段 = 8，表示东线被拆成 8 个停留/迁徙段。
2. 里程 = 3500 km，由 8 段 segment_km 相加。
3. 平均采蜜率 = 86 / 167 = 51.5%，表示 167 个停留天气日中有 86 天 good_honey_day = 1。
4. 沿途平均风险 = 8 个路段 climateRiskIndex 的简单平均，约 0.76。
5. 根据页面阈值，0.76 ≥ 0.62，因此解释为“沿途有效采蜜窗口受限，气候生产风险偏高，可能增加单箱产出与收入的不确定性”。
6. 风险链会进一步指出高风险节点，例如安徽、山东、辽宁、黑龙江、福建等段风险较高。
7. 点击某个节点后，聚焦卡会显示该段风险指数、风险等级、平均采蜜率、平均 NWI 和主要风险来源。

换句话说，“当前路线风险解释”不是单个天气值，而是路线级聚合：

- 先在路段层计算 climateRiskIndex；
- 再对当前路线的所有可用路段求均值；
- 同时用总 good_days / 总 weather_day_count 计算路线平均采蜜率；
- 最后用阈值把数值翻译成经营风险语句。

## 18. 需要避免的误读

1. NWI 高不等于一定有收益。只有 NWI 高、good_honey_day = 1、蜂农在该地停留且蜜源处于花期时，才进入 L5 有效采蜜窗口。
2. climateRiskIndex 是气候生产压力指数，不是收入损失率。它解释天气窗口对生产的压力，不直接等于利润下降百分比。
3. 路线平均风险是路段简单平均，不按里程或停留天数加权。
4. 平均采蜜率是按总天气天数加权，因为它使用总 good_days / 总 weather_day_count。
5. 授粉案例只表示地区/作物案例匹配，不代表该路段一定发生授粉合同。
6. 农药使用强度是全国背景层，不代表具体路线暴露。
7. 2024/2025 财务和行业部分字段带估算/预估性质，不能当作逐户实测。
8. 当前 index 默认 2020s；项目中存在年代切换组件，但当前 index 未挂载。

## 19. 一句话总结

当前 index 页面是一套以“时间弧线”为核心的流动养蜂路线分析系统：左侧选择路线，中间把停留、花期、天气、有效采蜜与 NWI 放在同一时空轨道上，右侧把这些生产窗口错位转译为路线风险、生计韧性、模式利润、收支结构和市场环境解释。核心风险指数 climateRiskIndex 由适宜采蜜日不足、连续坏天气、降雨暴露和高温暴露共同构成；核心生产窗口 L5 则由停留期、天气适宜和花期三者交集决定。
