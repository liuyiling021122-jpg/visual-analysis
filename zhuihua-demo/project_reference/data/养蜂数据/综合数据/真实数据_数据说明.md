# 真实数据.csv 数据说明

## 一、基础元数据

- **文件名**
- **位置**：综合数据/：`真实数据.csv`
- **文件大小**：约 524 KB
- **记录数**：1,179 行
- **字段数**：287 列
- **时间跨度**：1961–2025 年
- **覆盖对象**：中国全国及 31 个省
- **数据来源**：18 个真实数据表整合
- **编码格式**：UTF-8 with BOM
- **核心筛选字段**：`data_table`（标识每行数据来源）

## 二、内容与结构描述

### 概要

本数据集是围绕中国蜂业生产、蜂农经营、转地放蜂、蜜源环境、授粉服务与市场价格等主题整理形成的综合型真实数据文件。数据采用“纵向整合”的方式，将多个来源和主题不同的表合并在同一个 CSV 中，并通过 `data_table` 字段标识每一行所属的原始数据表。使用时应先按照 `data_table` 筛选出相应子表，再进行分析和可视化。

本数据集共包含 18 个子表，内容大体可以分为以下几个模块：

1. **蜂业生产模块**  
   包括全国和分省蜂群数量、蜂蜜产量、单群产量、蜂种构成等数据，可用于分析中国蜂业生产规模的长期变化和空间分布。

2. **蜂农经营与经济收益模块**  
   包括养蜂户数、从业人数、转地比例、蜂农收入、成本、利润，以及不同养殖模式下的收益结构，可用于分析蜂农经营压力和不同养殖方式的经济差异。

3. **市场价格与贸易模块**  
   包括蜂蜜收购价、零售价、出口量、出口额、出口单价，以及蜂王浆、蜂胶、蜂蜡、花粉等蜂产品价格，可用于分析蜂产品市场变化和价格结构。

4. **自然环境与蜜源模块**  
   包括主要养蜂省份的气候因子、油菜种植面积、主要蜜源植物特征、各省蜜源植物花期历等数据，可用于分析气候、花期、蜜源资源与蜂业生产之间的关系。

5. **转地放蜂与授粉服务模块**  
   包括转地放蜂路线分段数据、路线汇总数据、水果授粉依赖性、授粉服务价格案例等，可用于分析蜂农迁徙路径、授粉需求和蜂业服务价值。

## 三、处理与质量信息

### 3.1 数据来源

数据从以下公开渠道采集：

- **FAOSTAT**：下载了 1961 年以来的蜂群数量和蜂蜜产量时间序列
- **国家统计局**：提取了人口、GDP、农村收入、农药使用量、果园面积、水果产量、油菜面积等数据
- **中国蜂产品协会**：整理了 2000 年后的蜂群估算、产量、收购价和零售价数据
- **海关总署**：汇总了蜂蜜出口量额和进口量
- **企查查**：查询了蜂业企业工商注册数据
- **国家蜂产业技术体系**：提取了 2012 年蜂农收支基线调查数据
- **中国气象局**：提取了养蜂省份的气象观测数据
- **行业文献**：整理了花期、蜜源植物特征和转地路线资料
- **各省畜牧站**：获取了分省蜂群统计数据

### 3.2 处理流程

1. 从各渠道下载和提取原始数据
2. 中文列名统一翻译成英文
3. 清理了多余空行、修复了跨年日期错误
4. 以年份和省份为主键合并多来源数据
5. 重叠年份的共用指标交叉验证，确认一致
6. 添加 `data_table` 字段标识来源，纵向拼接

### 3.3 数据限制

1. **子表字段差异较大**  
   由于多个主题表被纵向合并，同一行只在部分字段上有有效值。进行分析前必须先依据 `data_table` 筛选子表，不能直接把全部 287 个字段作为同一张完整宽表使用。

2. **早期数据字段较少**  
   1961 年以来的长序列主要集中在蜂群数量、蜂蜜产量和单产等基础生产指标。蜂农经济、市场价格、气候因子等数据主要集中在 2000 年以后。

3. **部分数据存在统计口径差异**  
   蜂群数量存在不同来源和口径，例如 FAO 口径与国内估算口径可能存在差异。跨表比较时需要说明具体采用的口径。

4. **部分数据为估算或插补值**  
   分省蜂群、蜂农户数、部分经济字段和部分 2025 年指标包含插补、估算或预测性质，不宜作为精确统计值使用。

5. **价格数据未进行通胀调整**  
   蜂蜜收购价、零售价、出口单价等均为名义价格，若进行长期价格趋势比较，应进一步进行通胀修正。

6. **路线与花期数据具有参考性质**  
   转地放蜂路线和蜜源花期受到年份、气候、市场和蜂农个体策略影响，数据更适合用于典型路径和时空关系展示，不宜理解为所有蜂农的真实轨迹。

## 四、使用说明

### 4.1 使用方式

用 `data_table` 筛选需要的表即可。这个数据集适合做需要引用真实统计数据的分析，比如产量趋势、价格变化、出口贸易、蜂农效益等。

### 4.2 使用分析任务
结合课程可视分析系统设计，本数据集可以支持以下分析任务：

1. **蜂业生产长期趋势分析**  
   分析中国蜂群数量、蜂蜜产量、单群产量在 1961–2025 年间的变化。

2. **蜂业空间格局分析**  
   分析不同省份蜂群数量、油菜面积、气候条件和蜜源资源的空间差异。

3. **转地放蜂路径分析**  
   通过路线分段数据展示蜂农如何随花期和蜜源分布进行跨区域迁徙。

4. **蜜源花期与养蜂节律分析**  
   将蜜源植物花期、省份和路线结合，分析转地养蜂“追花逐蜜”的时空逻辑。

5. **蜂农经济收益分析**  
   对比蜂农收入、成本、利润率以及不同养殖模式下的收益差异。

6. **授粉服务价值分析**  
   结合水果授粉依赖性和授粉服务价格，分析蜜蜂在果园授粉和农业生态系统中的服务价值。

7. **气候环境影响分析**  
   结合气温、降水、极端高温、花期提前等指标，分析环境变化对蜂业生产和转地养蜂的潜在影响。
