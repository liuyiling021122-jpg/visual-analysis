# weather_daily_migration_routes.csv 数据说明

## 一、基础元数据

- **位置**：datasets/`weather_daily_migration_routes.csv`
- **文件大小**：约 713 KB
- **记录数**：4,927 行
- **字段数**：33 列
- **时间跨度**：1985–2025 年（逐日）
- **覆盖对象**：19 条转地路线上 50 个地点
- **数据来源**：Open-Meteo Historical Weather API（基于 ERA5 再分析数据）
- **编码格式**：UTF-8 with BOM

## 二、数据内容

本数据集为迁移路线数据中每段路的目的地提供了**逐日气候数据**，覆盖该路段停留期间以及前后各 10 天的天气情况。每条记录对应"一个地点 × 一天"。

### 字段说明

### 关键设计

- **前后 10 天缓冲期**：每条记录包含停留期前后各 10 天的天气数据，由 `buffer_before` 和 `buffer_after` 字段标识。这可以支撑"有效采蜜窗口"分析——例如在花期到来前 10 天观察天气变化趋势，或在离开后 10 天内继续跟踪天气对蜂群的影响。
- **蜜源补充变量**：新增日照时长、短波辐射、相对湿度、蒸散发、露点温度、云量等指标，直接关联蜜源植物泌蜜条件。
- **采蜜适宜度衍生指标**：`good_honey_day` 标记当日是否适合蜜蜂采蜜（无雨、风力小、温度适中），`bad_weather_streak` 统计连续不适宜天数，`honey_condition_score` 和 `nectar_weather_index` 从多维度综合评估泌蜜条件。
- **天气描述**：WMO 代码已转译为中文描述（晴/少云/多云/阴/小雨/中雨/大雨/雪/雷暴等），便于直接用于可视化标签。
- **停留期标识**：`in_stay_period` 字段可以直接筛选出蜂农在该地实际停留期间的天气数据，用于计算有效采蜜天数。

## 三、覆盖范围

### 路线覆盖

共 19 条路线，覆盖所有经典路线（东线、中线、西线、南线）、变体路线（川滇黔线、粤湘鄂线等）和蜂农个案（冯平安、凌雄俊、陈志军等）。

### 时间覆盖

路线时间分为两类：
- **个案年份**：1990、1995、2024、2025 年——对应蜂农个案的真实迁徙记录
- **经典路线**：1985（代表示 1980s）、2005（代表示 2000s）、2024（代表示 2020s）——经典路线没有绑定具体年份，按所属年代选取代表年份

### 地点覆盖

共 50 个地点，涵盖：
- 省级：广东、云南、四川、内蒙古等
- 市级：浙江江山、安徽黄山、福建泉州、黑龙江哈尔滨等
- 部分精确坐标地点：广东清远、贵州安顺、内蒙古赤峰等

## 四、数据来源

本数据集使用 Open-Meteo 的历史天气 API 获取。该 API 提供基于 ERA5（ECMWF 第五代大气再分析数据集）的全球历史天气数据，空间分辨率约 0.25°×0.25°。ERA5 是气象学领域广泛使用的再分析数据集，覆盖 1940 年至今。

## 五、数据限制

- 部分经典路线没有绑定具体年份，使用年代代表年份（1985、2005、2024）替代，可能无法反映逐年的气候波动
- 坐标精度受限于 ERA5 网格分辨率（约 27km），小范围内实际天气可能与网格值有偏差
- 4 个 API 请求因连接问题失败（北京 1985 年、山东 2005 年、广西 2024-2025 年、河北保定 2024 年），对应路段缺少该时间窗口的天气数据
- 天气代码描述为通用翻译，极端天气（如雷暴+冰雹）在路线途经时段内较少出现
- 数据为 ERA5 再分析估算值，并非实测站观测值，反映的是网格区域的平均状况

## 六、使用方式

按 `route_name` 筛选目标路线，按 `location` 筛选目标地点，按 `in_stay_period` 筛选停留期数据。

主要用途：
- 计算每条路线在每个地点停留期间的**有效采蜜天数**（无雨、温度适宜、风力较小的天数）
- 比较不同路线在相同季节的**天气风险**（降雨频率、极端天气）
- 分析**花期提前**对蜂农采蜜窗口的影响（对比不同年代相同地点的天气模式）
- 结合路线时间表判断蜂农**到达时机**是否匹配当地天气条件
