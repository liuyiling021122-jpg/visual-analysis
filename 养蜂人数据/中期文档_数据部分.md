## 数据说明

### 数据来源

本研究所用数据从多个公开渠道采集整理，涵盖中国蜂业 1961–2025 年的核心指标：

| 数据内容 | 来源 |
|----------|------|
| 蜂群数量、蜂蜜产量（1961–1999） | 联合国粮农组织（FAOSTAT）公开数据库 |
| 蜂蜜产量、蜂群（2000–2025） | 中国蜂产品协会年度产情报告 |
| 出口量、出口额 | 中国海关总署统计月报/年鉴 |
| 收购价、零售价、批发价 | 中国蜂产品协会市场价格监测 |
| 蜂农收支 | 国家蜂产业技术体系调查数据（2012 年基线调查 + 前后推估） |
| 人口、GDP、农村收入、农药使用、果园面积等 | 中国国家统计局（NBS）统计年鉴 |
| 美国蜂蜜价格 | 美国农业部（USDA）市场报告 |
| 气候数据 | 中国气象局观测数据 |
| 蜜源植物特征和花期 | 《中国蜜源植物志》等行业文献 |
| 蜂业企业数量 | 企查查工商注册数据 |
| 分省蜂群数据 | 各省农业农村厅/畜牧站 |

### 数据内容

全部数据整合为 22 张原始数据表（存放在 `datasets/` 目录），另按模拟数据和真实数据拆分为两个汇总文件（存放在 `综合数据/` 目录）。数据覆盖范围如下：

- **生产端**：全国及分省的蜂群数量、蜂蜜产量、蜂蜜单产
- **市场端**：蜂蜜出口量额、收购价、零售价、批发价，蜂王浆、花粉、蜂胶等蜂产品价格
- **蜂农端**：养蜂户数、从业人数、转地比例、蜂农详细收支、分四种养殖模式（大转地/小转地/定地意蜂/定地中蜂）的利润分解
- **气候环境**：主要养蜂省份的气温、降水、无霜期、日照、极端天气、花期提前天数
- **蜜源植物**：17 种主要蜜源植物的特征信息、24 省的花期历
- **转地放蜂**：蜂农转地放蜂的经典路线及历史变化
- **授粉服务**：22 种水果的授粉依赖性、各地授粉服务市场价格案例及模拟时间序列
- **模拟数据**：基于真实参数模拟的蜂场微观经营数据、县级数据和省级面板数据

### 处理流程

**1. 原始数据采集**

数据按类型从不同渠道分别获取：FAOSTAT 下载长序列时间数据，国家统计局提取年度统计数据，蜂产品协会整理行业监测数据，海关总署汇总贸易数据，其余数据来自企查查、气象局和行业文献。

**2. 数据清洗与标准化**

- 将中文列名统一翻译为英文命名，消除命名风格差异
- 检查缺失值，确认所有缺失均为结构性缺失（如 2000 年前无收购价记录），不做填充
- 清理 16 个文件末尾多余空行，统一 UTF-8-BOM 编码和数值格式
- 修复转地路线数据中 6 处跨年日期错误（结束于次年 1 月误写为同年）
- 重构蜂种构成数据格式，移除注释行和分隔行

**3. 数据合并与一致性校验**

以年份和省份为主键，将不同来源的时间序列逐一合并。重叠年份的共用指标（蜂群数量、蜂蜜产量、养蜂户数等）在不同表之间逐项对比验证，确认完全一致。

### 数据限制

- **模拟数据**：所有 `sim_` 开头的表基于真实参数生成，适合趋势分析，不能作为精确统计数据引用
- **时间覆盖**：1961–1993 年仅含生产和人口等 7 个字段，2000 年后才完整；2025 年部分数据为行业预估
- **口径差异**：蜂群数量存在 FAO 口径（偏高）和国内学术口径（偏低）两套体系，差异约 30%–50%
- **价格数据**：均为名义价格，未扣除通胀
- **蜂农收支**：2017 年后为按增长率推估值，非逐年实际调查

数据相关工作已全部完成，具体进展如下：

**数据采集**：已完成全部 22 个数据表的采集和整理。原始数据从 FAOSTAT、国家统计局、中国蜂产品协会、海关总署等公开渠道获取，时间跨度 1961–2025 年。
